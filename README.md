# MovieMatch

A group swipes yes/no on movies together; the moment everyone likes the same one, MovieMatch calls it a match.

> Work in progress — this README is a placeholder and will be replaced with full setup/architecture docs once the app is built out.

## Tech stack

- Next.js (App Router, TypeScript)
- Tailwind CSS + shadcn/ui
- Framer Motion
- Prisma ORM + Postgres (Neon)
- Auth.js (NextAuth v5) — Google OAuth + email/password
- TMDB API
- SWR polling
- Jest + Playwright

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
